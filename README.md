# YuMark

YuMark 是一款面向 Windows 的 Markdown 编辑器，适合记录日常笔记、整理知识库和撰写长文档。你可以直接查看排版效果，也可以切换到 Markdown 文本或分屏视图，按自己的习惯写作。

[下载最新版本](https://github.com/JunYuZhang0812/YuMark/releases/latest) · [查看更新记录](https://github.com/JunYuZhang0812/YuMark/releases) · [反馈问题](https://github.com/JunYuZhang0812/YuMark/issues)

## 下载与安装

当前提供 Windows 64 位安装包。

1. 打开[最新版本下载页](https://github.com/JunYuZhang0812/YuMark/releases/latest)。
2. 在 **Assets** 中下载名称以 `x64-setup.exe` 结尾的安装包。
3. 双击安装包，按照提示完成安装，然后打开 YuMark。

正常安装只需要下载 `.exe` 文件，其他附件无需手动下载。

## 开始使用

1. 按 `Ctrl+Shift+O` 打开存放 Markdown 文档的文件夹。
2. 从侧边栏选择文档，开始阅读或编辑。
3. 根据需要选择实时预览、源码模式或分屏预览。
4. 按 `Ctrl+S` 保存修改。

文档较多时，可以使用 `Ctrl+P` 快速打开文件，或使用 `Ctrl+Shift+F` 搜索工作区内容。

## 主要功能

### 按习惯选择编辑方式

- **实时预览**：在写作过程中直接查看排版效果。
- **源码模式**：直接编辑 Markdown 文本，方便调整格式。
- **分屏预览**：一边编辑，一边查看文档呈现效果。

### 方便的内容排版

通过快捷插入菜单添加标题、代码块、表格、图片等内容。选中文本后，可以使用悬浮工具调整加粗、斜体、删除线、高亮和文字颜色等格式。

图片支持缩放和编辑；流程图支持可视化调整节点与连线，方便整理步骤和表达思路。

### 整理文档与知识库

- **文件浏览与多标签页**：在多篇文档之间切换。
- **目录导航**：按标题查看文章结构，快速跳转到对应段落。
- **搜索与替换**：查找当前文档内容，或搜索整个工作区。
- **标签**：按标签浏览相关文档。
- **反向链接**：查看哪些文档引用了当前文章。
- **关系图谱**：直观浏览文档之间的联系。

### 调整阅读和写作环境

支持浅色、深色主题，并可在设置中调整字体、配色和快捷键，让阅读与编辑更符合个人习惯。

## 常用快捷键

| 操作 | 默认快捷键 |
| --- | --- |
| 保存文档 | `Ctrl+S` |
| 打开文件夹 | `Ctrl+Shift+O` |
| 快速打开文件 | `Ctrl+P` |
| 切换源码与实时预览 | `Ctrl+/` |
| 查找 | `Ctrl+F` |
| 查找并替换 | `Ctrl+H` |
| 全局搜索 | `Ctrl+Shift+F` |
| 显示或隐藏侧边栏 | `Ctrl+B` |
| 关闭当前标签页 | `Ctrl+W` |
| 下一个标签页 | `Ctrl+Tab` |
| 上一个标签页 | `Ctrl+Shift+Tab` |
| 打开命令面板 | `Ctrl+Shift+P` |

可以在「设置 → 快捷键」中修改键位。
